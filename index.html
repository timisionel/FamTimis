📋 COME CONFIGURARE (una sola volta)

1

Crea il database gratuito

Vai su console.firebase.google.com
→ Aggiungi progetto → nome famtimis → continua (Analytics: off) → Crea progetto.

2

Attiva il Realtime Database

Nel menu sinistra → Build → Realtime Database → Crea database → Europa → Modalità test → Fine.
Poi Regole → sostituisci tutto con:
{ "rules": { ".read": true, ".write": true } } → Pubblica.

3

Copia l'URL del database

In cima alla pagina vedi qualcosa come:
https://famtimis-abc12-default-rtdb.europe-west1.firebasedatabase.app
Copia quell'URL e incollalo qui sotto.

Copia l'URL dalla console Firebase (Realtime Database)
Inserisci l'URL del database Firebase (deve contenere firebasedatabase.app o firebaseio.com)
Parola segreta condivisa con la famiglia — tutti devono inserire lo stesso codice
Inserisci un codice di almeno 4 caratteri
